# iZi Pet — Android overlay project

Полный исходный проект извлечён из загруженного `app-debug.apk`: использованы исходные 31 SVG и исходный `manifest.json`. Пакет приложения: `com.izi.pet`.

## Сборка

Требования: Android Studio с JDK 17, Android SDK Platform 35 и Gradle 8.9.

Локально:
```bash
gradle --version
gradle assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`.

Через GitHub:
1. Распакуйте архив в корень репозитория.
2. Закоммитьте файлы в ветку `main`.
3. Откройте Actions → Build iZi Pet APK → Run workflow.
4. Скачайте artifact `izi-pet-debug-apk`.

## Установка и разрешение

1. Установите APK на Android 10+.
2. Откройте iZi Pet.
3. Нажмите «Выпустить iZi».
4. Разрешите «Поверх других окон».
5. Вернитесь в приложение. Питомец появится поверх других приложений.
6. Нижняя панель управления остаётся интерактивной; полноэкранное окно персонажа не перехватывает касания.
7. «Забрать домой» останавливает сервис и удаляет оба окна.

## Сервер

Запрос отправляется из `OverlayService.java` через `HttpURLConnection`:
```json
{"message":"текст пользователя"}
```
Ожидаемый ответ:
```json
{"reply":"ответ iZi"}
```
URL: `https://wispy-pond-9c0b.zadeakber.workers.dev`

Это соответствует прежнему `index.html` из присланного APK, в котором использовалось поле `message`. Если Worker принимает другое поле, измените `body.put("message", message)`.

## Как устроены окна

- Персонаж: полноэкранный WebView с `FLAG_NOT_TOUCHABLE | FLAG_NOT_FOCUSABLE`.
- Панель: отдельное компактное нативное окно, которое становится фокусируемым при открытии чата.
- Поэтому касания сквозь персонажа проходят в приложения, а поле ввода панели может вызвать клавиатуру.

## Примечания и ограничения

- Проект подготовлен по содержимому предоставленного APK. Это исходный проект для сборки, а не обещание, что APK уже прошёл запуск на физическом устройстве.
- Микрофон пока не записывает звук: кнопка 🎤 показывает «Слушаю...». Для настоящей записи потребуются runtime-разрешение RECORD_AUDIO, отдельный корректно объявленный foreground-service microphone type и пользовательский сценарий запуска.
- Для публикации в Google Play нужно пересмотреть targetSdk и тип foreground service согласно актуальным требованиям Google Play/Android. Сейчас targetSdk 32 выбран для совместимого тестового sideload-сценария Android 10+.
- В WebView используется локальный `file:///android_asset/index.html`; сетевые обращения выполняет Java, поэтому CORS браузера не участвует.
